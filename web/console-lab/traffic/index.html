CSV format and counting rules

Use date,page,channel,sessions,pageviews, with one row per date, landing page and acquisition channel. Each session should belong to only one row. Use path-only labels, no personal data, and only aggregate data you’re authorized to use. Missing days are not assumed to be zero. Pageviews are attributed to the session’s landing page in this format. Unique visitors, conversions, and bounce rates are not measured.
