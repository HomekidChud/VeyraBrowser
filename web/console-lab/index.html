Admin-only, bounded operations

Activity is aggregate-only: active session totals and request counts, without browsing URLs or page content. Analytics and live status use VeyraServer’s existing admin/model/robot APIs. Agent jobs make outbound requests to the seed URLs you configure; each run is limited to 50 pages and depth 5. Saved agent profiles stay in this browser. Diagnostic probes remain capped at 20 requests per run and 3 server batches per page load.
