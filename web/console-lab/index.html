The local suite generates console output and temporary page errors. The server suite sends at most 20 sequential resource requests per run through VeyraServer: health responses, standard HTTP status fixtures, reserved .invalid hosts, and missing resources. Image, script, and stylesheet loads exercise the browser's resource-error path without page-side fetch/CORS ambiguity. No crawler/session creation, login, writes, retries, background loop, or backup access. Stop halts remaining probes; up to three server batches are allowed per page load.
