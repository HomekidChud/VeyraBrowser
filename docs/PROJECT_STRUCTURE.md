# Project structure

| Directory | Responsibility |
| --- | --- |
| `web/` | Static application served by GitHub Pages and copied into the Android app. |
| `web/src/` | Browser modules, page UI, DevTools, extensions, and device cast code. |
| `web/styles/` | Browser application styles. |
| `web/assets/` | Browser icons and visual assets. |
| `scripts/` | Source validation tools. |
| `android/` | Capacitor-generated Android project after `npm run sync`. |
